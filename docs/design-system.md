# Woosoo GrillPad Design System

## Color system

- Background: #252525
- Deep Surface: #1B1B1B
- Accent Gold: #F6B56D
- White: #FFFFFF
- Black: #000000

Use the accent gold sparingly for primary CTAs, active/selected states, totals, highlights, and logo only.

## Typography system

- Heading: Raleway
- Body: Kanit

## Spacing scale

- Page padding: 24px (`p-6`)
- Card padding: 24px to 40px depending on density

## Animation timing

- Duration: 180–260ms
- Easing: ease-out for entry, ease-in for exit

## Button variants

- Primary: gold accent background
- Ghost: translucent surface with soft border
- Danger: destructive actions only

## Card variants

- Default: `.gp-card`

## Refill-mode styling

- Always show a refill-mode banner.
- Hide non-refill items entirely.

## Accessibility rules

- Maintain high contrast on dark surfaces.
- Minimum tap target height: 48px (buttons use 48px+).

## Tablet safe areas

- Always include `viewport-fit=cover`.
- Keep bottom bars above home-indicator areas.
